# SWASTHYAKOSH

SwasthyaKosh is a centralized digital platform for storing and managing medical prescriptions and health records securely.

Blending traditional healthcare values with modern technology, it ensures long-term accessibility, continuity, and reliability of medical data.

📌 **Problem Statement**

Medical prescriptions are often fragmented across hospitals and physical records, leading to data loss, repeated tests, and inefficient healthcare decisions.

💡 **Solution Overview**

SwasthyaKosh creates a unified digital health repository for each individual, enabling lifelong storage and easy access to prescriptions and medical history.

🔑 **Key Features**
- Secure authentication
- Centralized prescription storage
- Organized medical history
- Multi-device accessibility
- Scalable system architecture

🛠️ **Tech Stack**
- HTML, CSS, JavaScript (React via Vite)
- Firebase Authentication & Database
- Firebase Hosting

📈 **Future Scope**
- Doctor and hospital integration
- AI-based prescription insights
- Advanced data security
- Health analytics
